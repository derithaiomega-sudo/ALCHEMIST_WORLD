# Entity Model

Entity: id, type, name, optional description/state/owner/metadata, createdAt, updatedAt.

Initial types: WORLD, PROJECT, PERSON, TEAM, AGENT, SKILL, TOOL, IDEA, PROBLEM, SYSTEM, TASK, DOCUMENT, KNOWLEDGE, DECISION, EXPERIMENT, WORKFLOW, REPOSITORY, CODE, ARTIFACT, PRODUCT, RESOURCE, EVENT, MEMORY.

Relationships are first-class.
