# v2.3 — Real World App Bridge

Connects app-facing input and persistence ports to the canonical vertical-slice runtime.

## Boundary
- CommandBus: deterministic command -> event boundary.
- RealWorldBridge: app-facing orchestration over canonical SliceState.
- StoragePort: platform-neutral persistence boundary.
- BridgeSnapshot: versioned save envelope with checksum.

## Runtime path
INPUT -> COMMAND BUS -> WORLD STATE -> EVENT TRACE -> PERSISTENCE

This is a TypeScript runtime boundary, not yet a compiled mobile build.
