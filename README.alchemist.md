# 🧪 Alchemist World

> The Operating System for Turning Intent into Reality.

Alchemist World is an AI-native workspace/ecosystem where human intent becomes knowledge, systems, code, actions and measurable reality.

## Core loop

`INTENT → CLARITY → SYSTEM → CODE → ACTION → REALITY → LEARNING ↺`

## v0.4-build

First vertical slice: `intent → project → context → plan → repository change → validation → documentation → memory`.

## World surfaces

- 🧙 Tower — orchestration
- 📚 Library — knowledge and persistent memory
- ⚒️ Forge — code and artifacts
- ⚗️ Crucible — problems and transformations
- 🌱 Garden — ideas and potential
- 🔭 Observatory — metrics and validation
- 🔥 Eternal Flame — automation
- 🐍 Ouroboros — feedback and learning

## Repository layout

`apps/world`, `packages/core`, `packages/entities`, `packages/memory`, `packages/alchemy`, `packages/agents`, `packages/skills`, `packages/tools`, `docs`, `memory`, `.github`.

## Engineering principles

Repository is durable project memory. Contracts precede autonomous behavior. Agents use least privilege. Important changes are deterministic through CI. Architecture changes are recorded as ADRs. The Creator retains judgment over consequential actions.
